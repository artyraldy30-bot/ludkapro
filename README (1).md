# Колесо Квантастики

Одностраничная игра для сотрудников отдела продаж. Сайт статический и живёт на GitHub Pages. Коды, результаты и выбор приза хранятся в базе Supabase (бесплатный тариф подходит).

## Как это устроено
- В браузере **нет списка кодов**. Сайт отправляет введённый код на сервер, и сервер отвечает «подходит», «уже использован» или «не найден».
- В базе лежат только SHA-256 хэши кодов. Таблица кодов закрыта: из браузера её нельзя ни прочитать, ни изменить.
- **Приз выбирает сервер**, браузер только докручивает колесо до выпавшего сектора. Подменить выигрыш через консоль не получится.
- Код гасится атомарно: если два человека одновременно крутят с одним кодом, пройдёт только первый.
- Таблица результатов общая для всех и обновляется сама раз в 15 секунд.

## Содержимое проекта
- `index.html`: сайт и игровая логика.
- `supabase.sql`: схема базы, серверные функции и хэши новых кодов.
- `README.md`: эта инструкция.
- `.nojekyll`, `.gitignore`: служебные файлы.
- `kody-dlya-kolesa.txt`, `kody-dlya-kolesa.csv`: **секретные** коды для раздачи. В репозиторий не загружать.

## Настройка базы (один раз)
1. Зарегистрируйтесь на https://supabase.com и создайте проект (New project).
2. Откройте **SQL Editor**, вставьте содержимое `supabase.sql` целиком и нажмите **Run**.
3. Откройте **Project Settings → API** и скопируйте **Project URL** и ключ **anon public**.
4. В `index.html` в начале блока `<script>` заполните:
   ```js
   const SUPABASE_URL = 'https://xxxx.supabase.co';
   const SUPABASE_ANON_KEY = 'eyJ...';
   ```
   anon-ключ публичный по задумке: он позволяет только читать результаты и вызывать проверку кода и спин.
   Ключ **service_role** на сайт не вставляйте никогда.

## Публикация на GitHub Pages
1. Загрузите в репозиторий `index.html`, `README.md`, `.nojekyll`, `.gitignore`. Файл `supabase.sql` загружать не обязательно.
2. **Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`, **Save**.

## Призы и вероятности
- 500 ₽: 47%
- 1 000 ₽: 25%
- 2 000 ₽: 15%
- 4 000 ₽: 10%
- 7 000 ₽: 3% (джекпот)

Итого 100%, пустых секторов нет. Вероятности задаются в функции `spin` в `supabase.sql`.
На колесе 10 одинаковых секторов (500 ₽ ×3, 1 000 ×2, 2 000 ×2, 4 000 ×2, 7 000 ×1), чтобы все суммы читались крупно. Размер сектора на шанс не влияет: приз выбирает сервер, а колесо останавливается на выпавшей сумме.

## Как обновить уже работающий сайт
1. Supabase → SQL Editor → вставьте **весь** новый `supabase.sql` → Run. Файл можно запускать повторно: результаты и использованные коды сохранятся.
2. Перенесите свои `SUPABASE_URL` и `SUPABASE_ANON_KEY` в новый `index.html` и загрузите его на GitHub.

## Администрирование (Supabase → Table Editor или SQL Editor)
- Все результаты: `select * from results order by amount desc;`
- Кто каким кодом играл: столбцы `used_at` и `used_by` в таблице `codes`.
- Удалить ошибочный результат: `delete from results where id = ...;`
- Сбросить всё для нового розыгрыша:
  `truncate results; update codes set used_at = null, used_by = null;`
- Новые коды: сгенерируйте их и добавьте хэши:
  `insert into codes (code_hash) values (encode(extensions.digest('НОВЫЙКОД','sha256'),'hex'));`
