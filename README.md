# Колесо Квантастики

Одностраничная игра для сотрудников отдела продаж. Это статический сайт: установка зависимостей и сборка не нужны.

## Содержимое проекта
- `index.html` — сайт и игровая логика.
- `README.md` — инструкция.
- `.nojekyll` — настройки публикации на GitHub Pages.
- `.gitignore` — стандартные исключения.
- `kody-dlya-kolesa.txt` и `kody-dlya-kolesa.csv` — список кодов для организатора.

## Публикация на GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html`, `README.md`, `.nojekyll` и `.gitignore` в корень репозитория.
3. В репозитории откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации GitHub покажет адрес сайта.

## Важно о кодах и защите
Файлы кодов не загружайте в публичный репозиторий, если коды должны оставаться секретными. Добавляйте их только в приватное хранилище организатора.

Текущая версия хранит список допустимых кодов в JavaScript и использованные коды/результаты в `localStorage` браузера. Это подходит для демонстрации, но не обеспечивает защищённый реальный розыгрыш: коды можно обнаружить в исходниках, а локальные данные — очистить. Для настоящего розыгрыша между сотрудниками нужна серверная проверка кодов и общая база данных, где код погашается ровно один раз.
